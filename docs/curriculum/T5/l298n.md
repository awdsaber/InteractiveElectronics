# L298N Module

*The hot classic*

> At 1 A the L298's bipolar output stage drops about 1.8 V (typical, up to 3.2 V worst case) and turns it into heat, nearly 4 times the TB6612's loss.

- **Lesson id:** `l298n` · **Track:** T5 Motors & drivers
- **fig:** 30 (video Fig. 06). Provisional: sidebar order.
- **Prerequisites:** `tb6612fng`, T2 `transistor-switch`
- **Power element:** `usb_plug` (powerLabel: "Plug USB"). The motor supply is the tweak `bat_sw`.
- **Behaviors:** `l298n`, `mcu-supply`, `serial-plotter`
- **transient:** true

## Learning goals

1. Explain why a bipolar (BJT) bridge loses volts where a MOSFET bridge loses only I·R: VCE(sat) on two transistors in series.
2. Read the L298 datasheet's saturation-voltage table and turn it into motor voltage, efficiency and heat.
3. Do a junction-temperature check with Rθ values, with and without the module's heatsink.
4. Know the module's quirks: external flyback diodes, the 78M05 regulator and its 5 V-EN jumper, and the ENA/ENB jumpers.
5. Decide when the L298N is acceptable (cheap, robust, up to 46 V) and when to avoid it (battery robots at 5–12 V).

## Circuit

Same averaged half-bridge model as `tb6612fng`. The difference is the drop. Each conducting transistor is a resistor fitted to the datasheet's *typical* VCE(sat): source side 0.95 V at 1 A and 2.0 V at 2 A, roughly 1.0 Ω. Sink side 0.85 V at 1 A and 1.7 V at 2 A, roughly 0.85 Ω. Each half gets the average, 0.925 Ω, giving **1.85 Ω** total in the path. Below about 0.3 A the real drop does not shrink to zero the way a resistor's does (SIM NOTE: a diode+resistor fit).

Expected values at 100 % forward on 7.4 V (no load, I ≈ 0.15 A):
- The motor gets 7.4 − 0.15 × (1.85 + 0.15) ≈ 7.1 V. The low-current drop is underestimated here (see above).
- With a moderate load drawing 1 A, the motor gets 7.4 − 1 × 2.0 ≈ **5.4 V**, and the bridge burns 1² × 1.85 ≈ **1.85 W** per channel.

### Behaviors

- **`l298n`**. Same structure as `tb6612` (reads voltages relative to `bat_n`; VIH min 2.3 V and VIL max 1.5 V from the L298 datasheet, so 3.3 V logic is valid).
  - **Truth table:**

    | EN | IN1 | IN2 | mode | half A | half B |
    |---|---|---|---|---|---|
    | duty | H | L | forward | duty·Vs | 0 |
    | duty | L | H | reverse | 0 | duty·Vs |
    | H | IN1 = IN2 | | fast motor stop (brake) | same level | same level |
    | L | x | x | free-running stop (coast) | open | open |

    In PWM on EN, the off-phase is a *coast* (outputs off, current through the flyback diodes), not a brake. The average speed versus duty is therefore less linear than with the TB6612. The behavior approximates this by opening `en_a/en_b` for the (1 − duty) fraction in an averaged sense: half A is duty·Vs with the switch closed.
  - **Thermal:** P_total = Σ I² × 1.85 Ω + Vs × 0.013 A quiescent (13 mA typical with enabled outputs and zero load, approximate). It integrates T_j through Rθjc = 3 °C/W, Rθcs = 1 °C/W (pad/grease, approximate) and Rθsa (behavior param `rthSA`, default 15 °C/W for the module's small finned heatsink, approximate). With `heatsink:false` it uses Rθja = 35 °C/W.
  - **Thermal shutdown** at T_j ≥ 150 °C (outputs open, 20 °C hysteresis; the L298 datasheet lists 150 °C as the junction maximum).
  - **Inductive kick:** at each mode change, if the motor current is non-zero and the flyback diodes are missing, the open switches see L·di/dt. The engine's switch Roff produces this in transient. The behavior also flags `kick_V`.
  - **Publishes:** `mode`, `drop_V` (Vs − |V(out1) − V(out2)|), `bridge_W`, `tj`, `efficiency` (motor power / supply power) and `rpm_out`.
- **`mcu-supply`**, **`serial-plotter`**: see `arduino-uno`.

## Sketch

**Title:** Measure the drop · **board:** `uno` · **vcc:** 5

| Pin | L298N pin | PIN element |
|---|---|---|
| 5 (PWM) | ENA (jumper removed) | `pin5` |
| 7 | IN1 | `pin7` |
| 8 | IN2 | `pin8` |

```cpp
#define ENA 5
#define IN1 7
#define IN2 8

void drive(int speed) {               // -255..255, 0 = brake
  speed = constrain(speed, -255, 255);
  if (speed > 0) {
    digitalWrite(IN1, HIGH);
    digitalWrite(IN2, LOW);
    analogWrite(ENA, speed);
  } else if (speed < 0) {
    digitalWrite(IN1, LOW);
    digitalWrite(IN2, HIGH);
    analogWrite(ENA, -speed);
  } else {
    digitalWrite(IN1, LOW);           // IN1 = IN2 with EN high: fast stop
    digitalWrite(IN2, LOW);
    analogWrite(ENA, 255);
  }
}

void setup() {
  pinMode(ENA, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  Serial.begin(115200);
  Serial.println("L298N: stepping duty, watch the drop and the heatsink");
}

void loop() {
  for (int duty = 0; duty <= 255; duty += 51) {   // 0, 20, 40, 60, 80, 100 %
    drive(duty);
    Serial.print("duty_pct:");
    Serial.println(duty * 100 / 255);
    delay(3000);
  }
  drive(0);
  delay(2000);
  for (int duty = 0; duty <= 255; duty += 51) {
    drive(-duty);
    delay(1500);
  }
  analogWrite(ENA, 0);                // EN low: coast
  delay(3000);
}
```

## Failures

### F1: Remove the flyback diodes, then stop
- **Patches:** `{op:'remove', elementId:'d_a_hi'}`, `{op:'remove', elementId:'d_a_lo'}`, `{op:'remove', elementId:'d_b_hi'}`, `{op:'remove', elementId:'d_b_lo'}`
- **Sim shows:** the next time the sketch coasts (EN low) with current flowing, the motor inductance (0.5 mH) has nowhere to send its current. The voltage across the open `en_a` jumps far above 50 V and it fails short. The bridge is dead, and the next "forward" command shorts the battery through it.
- **Why:** the L298 datasheet requires external fast diodes (trr ≤ 200 ns). In a real PWM drive this happens at *every* PWM edge, so a module with missing or open diodes dies quickly. Energy check: ½ L I² = ½ × 0.5 mH × (0.5 A)² ≈ 63 µJ per event, tiny in energy but at a voltage that punches through silicon.

### F2: Run two motors at 1.5 A without the heatsink
- **Patches:** `{op:'set', elementId:'bat', key:'value', value:12}`, `{op:'set', elementId:'m1', key:'load', value:0.0075}`, `{op:'set', elementId:'behavior:l298n', key:'heatsink', value:false}`, `{op:'set', elementId:'behavior:l298n', key:'channels', value:2}`. Channel B mirrors A. A 12 V supply is needed, because on 7.4 V the stall current is only 7.4 / 6 Ω ≈ 1.2 A.
- **Sim shows:** loss ≈ 2 × 1.5² × 1.85 ≈ 8.3 W. T_j heads for 25 + 8.3 × 35 ≈ 316 °C, so thermal shutdown hits in seconds and the motors pulse on and off.
- **Why:** this is the main reason to avoid the L298N on a battery robot. With the heatsink (Rθ ≈ 3 + 1 + 15 = 19 °C/W) it is 25 + 8.3 × 19 ≈ 183 °C, still too hot. The L298 is only comfortable at well under 1 A per channel on this module.

### F3: Run it from a single Li-ion cell (3.7 V)
- **Patch:** `{op:'set', elementId:'bat', key:'value', value:3.7}`
- **Sim shows:** with a 0.5 A load the motor gets about 3.7 − 0.5 × 2 ≈ 2.7 V. After its own 0.5 A × 4 Ω drop, only 0.7 V of back-EMF is left, so the output turns at about 26 rpm instead of about 190 rpm. The bridge takes 27 % of the battery's energy.
- **Why:** the drop is fixed in volts, so it takes a bigger share of a low supply. The datasheet also wants Vs ≥ VIH + 2.5 V. A low-voltage robot needs a MOSFET driver (TB6612, DRV8833).

## Meet the board

The L298 is a 1980s bipolar design that is still everywhere, because the red module is cheap and tough. Each output is a pair of BJTs. A saturated BJT always has a **VCE(sat)** across it, and the current path goes through two of them.

From the datasheet (typical): source side **0.95 V** and sink side **0.85 V** at 1 A, for a **total of 1.8 V**. The guaranteed maximum at 1 A is 3.2 V, and at 2 A it is up to 4.9 V.

**Worked example:** a 7.4 V pack with the motor drawing 1 A. The motor sees 7.4 − 1.8 ≈ **5.6 V**, and the bridge dissipates 1.8 V × 1 A = **1.8 W**, so efficiency is about 5.6 / 7.4 ≈ **76 %**. The TB6612 at the same current loses 0.5 V and 0.5 W.

**Heat:** Rθjc = 3 °C/W, Rθja = 35 °C/W without a heatsink. Two channels at 1 A give 3.6 W, so T_j ≈ 25 + 3.6 × 35 = **151 °C** bare. That is at the 150 °C limit, which is why the module has a heatsink.

**Module quirks:** fit the 5V-EN jumper only when Vs ≤ 12 V, so the 78M05 does not overheat. Remove ENA/ENB jumpers to PWM. VIH is 2.3 V minimum, so 3.3 V MCUs can drive it.

**Where it still fits:** 12–46 V supplies, where 2 V is a small fraction, and in teaching kits.

## For mechanical engineers

> The TB6612 is a ball valve: wide open, the only loss is a little pipe friction (I·R). The L298 is a pressure-reducing check valve that always takes about 2 bar off the line whatever the flow, and that pressure drop times flow becomes heat in the valve body. On a 200 bar system nobody notices 2 bar. On a 7 bar system you have lost a quarter of your pressure. **Where it breaks:** a BJT's drop does rise with current (it is part resistive), and it also depends on temperature and part-to-part spread, so "2 V" is a rule of thumb, not a constant.

## Pro tips

1. Read saturation voltages from the *max* column for design and the *typ* column for expectations. On the L298, the gap (1.8 V typical versus 3.2 V max at 1 A) is the difference between a working robot and a sluggish one.
2. If you are stuck with an L298N, run it at a higher Vs and limit PWM to the motor's rated voltage. The fixed 2 V drop then costs a smaller fraction.
3. On these modules, check the flyback diodes with a meter's diode test (about 0.2–0.5 V one way for Schottky, open the other). Cheap boards sometimes have missing or reversed parts.

## Quiz

1. **A 7.4 V pack, the motor drawing 1 A, and a typical L298 total drop of 1.8 V. What voltage reaches the motor?**
   - 1.8 V
   - 5.6 V
   - 6.9 V
   - 7.4 V
   - **Answer:** 1. *Why:* 7.4 − 1.8 = 5.6 V.

2. **Both channels at 1 A (1.8 W each) with no heatsink (Rθja 35 °C/W, ambient 25 °C). What is the junction temperature?**
   - 63 °C
   - 88 °C
   - 151 °C
   - 252 °C
   - **Answer:** 2. *Why:* T_j = 25 + 3.6 × 35 = 151 °C, at the limit, so a heatsink is required.

3. **Why does the L298N module carry eight external diodes?**
   - To drop the voltage for the logic
   - The L298 has no internal flyback diodes, so the motor's inductive kick needs a path to the rails
   - Reverse-polarity protection
   - Indicator LEDs
   - **Answer:** 1. *Why:* the L298's BJTs have no body diodes (unlike MOSFETs), and the datasheet specifies external fast diodes.

4. **At 1 A from 7.4 V, roughly what is the bridge efficiency with the L298 versus a 0.5 Ω TB6612?**
   - 76 % versus 93 %
   - 50 % versus 75 %
   - 93 % versus 76 %
   - Both about 99 %
   - **Answer:** 0. *Why:* L298: (7.4 − 1.8)/7.4 ≈ 76 %. TB6612: (7.4 − 0.5)/7.4 ≈ 93 %.

## SIM NOTE

- PartKind: there is no Multiwatt15 package. This lesson uses `regulator-to220` with `params.package:'Multiwatt15'`, which needs a 15-leg staggered model in the part library.
- A better BJT-bridge drop model: a diode + series resistor per transistor, fitted to VCE(sat) at 0.5/1/2 A. This needs a `D` with a bidirectional option, or behavior-switched elements.
- In EN-PWM the off-phase is *coast* (fast decay through the diodes). The averaged-source model treats it like drive/brake, so the behavior should correct the effective average voltage when it computes the speed–duty curve.
- Behavior-param patches (`behavior:l298n`, keys `heatsink`, `rthSA`, `channels`), as in `interrupts-timers`.
- Inductive kick during transient depends on the SW Roff (1e9 Ω) giving a huge L·di/dt. Check that the engine reports it as an overvoltage burn rather than failing to converge.
